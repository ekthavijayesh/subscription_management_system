# Feature Catalogue

| Area | Admin | Staff | Customer |
| --- | --- | --- | --- |
| Identity | manage staff/customer access and permissions | own account | own account |
| CRM | all customers, assignment management | assigned customers | own profile only |
| Catalogue/plans | create, edit, archive | browse/select permitted active records | browse active records |
| Quotations | full lifecycle | create/manage within scope | view/accept own as approved policy allows |
| Subscriptions | all lifecycle actions | permitted scoped actions | view own; request cancellation |
| Invoices/payments | manage all | create/record permitted scoped records | own invoices, PDF, payment history |
| Tax/discounts | configure | apply only valid configured rules | view applied amounts |
| Reports/activity | organization analytics/audit | scoped reports/activity | own account/commercial data |

All features require responsive tables/forms/dialogs, search/filter/pagination where collections warrant it, loading skeletons, accessible empty/error states, validated forms, toast feedback, and server/RLS enforcement. Feature implementation order and definition of done are in `DEVELOPMENT_ROADMAP.md`.
